# Antigravity - CLI experimental de IA

## Descripcion

CLI experimental de IA. Proyecto en desarrollo activo.

## Instalacion

```bash
nxai install antigravity
```

O manualmente:

```bash
git clone https://github.com/antigravity-ai/antigravity
cd antigravity
# Sigue las instrucciones del proyecto
```

## Uso

```bash
antigravity --help
```

## Requisitos

- Git
- Conexion a internet

## Notas para Termux

Antigravity no tiene instalacion automatizada aun.
Clona el repositorio y compila segun las instrucciones del proyecto.

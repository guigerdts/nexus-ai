# Neovim

## Descripcion

Editor de texto moderno, fork de Vim con soporte nativo de LSP,
Arquitectura de plugins en Lua, terminal integrada, y arbol de
edicion.

## Instalacion

```bash
nxai install neovim
```

O manualmente:

```bash
pkg install neovim    # Termux
apt install neovim    # proot-Ubuntu
```

## Uso

```bash
nvim archivo.lua
nvim +PackerSync
```

## Notas para Termux

```bash
pkg install neovim
```

Neovim en Termux funciona bien. Para una experiencia completa
instala un Nerd Font y configura tu init.lua.

## Notas para proot-Ubuntu

```bash
apt install neovim
```

# Zsh — Z shell

## Descripcion

Zsh es un shell extendido con soporte para plugins, temas y personalizacion.
Ofrece autocompletado avanzado, correccion ortografica y un potente sistema
de scripting.

## Instalacion

```bash
nxai install zsh
```

O manualmente:

```bash
pkg install zsh      # Termux
apt install zsh      # proot-Ubuntu
```

## Uso

```bash
zsh
# O configurarlo como shell por defecto:
chsh -s $(which zsh)
```

## Notas para Termux

```bash
pkg install zsh
zsh --help
```

## Notas para proot-Ubuntu

```bash
apt install zsh
zsh --help
```

# Lazygit

## Descripcion

Interfaz interactiva para Git en la terminal. Permite visualizar el
arbol de commits, hacer staging, diff, commit, rebase, merge y mas
desde una TUI simple y rapida.

## Instalacion

```bash
nxai install lazygit
```

O manualmente:

```bash
pkg install lazygit   # Termux
apt install lazygit   # proot-Ubuntu
```

## Uso

```bash
lazygit
```

## Notas para Termux

```bash
pkg install lazygit
lazygit
```

Requiere una terminal que soporte TUI (tmux, termux-x11, o terminal
nativa de Termux).

## Notas para proot-Ubuntu

```bash
apt install lazygit
lazygit
```

# TypeScript

## Descripcion

Compilador oficial de TypeScript a JavaScript. Permite escribir
codigo tipado que se compila a JavaScript limpio y legible.

## Instalacion

```bash
nxai install typescript
```

O manualmente:

```bash
npm install -g typescript
```

## Uso

```bash
tsc --version
tsc --init
tsc
```

## Notas para Termux

```bash
pkg install nodejs
npm install -g typescript
```

## Notas para proot-Ubuntu

```bash
apt install nodejs npm
npm install -g typescript
```

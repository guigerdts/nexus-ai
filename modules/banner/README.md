# Banner — ASCII header de NEXUS AI

## Descripcion

El banner ASCII de NEXUS AI ya esta incluido en el framework.
Se muestra automaticamente al ejecutar el comando `nxai`.

**No requiere instalacion adicional.**

## Instalacion

El banner ya esta disponible. No es necesario instalar nada.

```bash
nxai help
# El banner se muestra al inicio del output
```

## Notas para Termux

```bash
nxai help
```

## Notas para proot-Ubuntu

```bash
nxai help
```

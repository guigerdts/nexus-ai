# Fabric - Framework open-source para automatizacion con IA

## Descripcion

Fabric es un framework open-source que permite automatizar tareas
cotidianas usando IA. Incluye patrones reutilizables (patterns)
para analisis, resumen, generacion y mas.

## Instalacion

```bash
nxai install fabric
```

O manualmente:

```bash
pip3 install --user fabric-ai
```

## Uso

```bash
fabric --help
fabric -p resumir < archivo.txt
```

## Requisitos

- Python 3.8+
- pip3

## Notas para Termux

Fabric funciona en Termux nativo. Asegurate de tener Python 3 instalado:

```bash
pkg install python
pip3 install --user fabric-ai
```

# Git — Sistema de control de versiones

## Descripcion

Git es un sistema de control de versiones distribuido, rapido y escalable.
Maneja proyectos desde pequenos a muy grandes con eficiencia y velocidad.

## Instalacion

```bash
nxai install git
```

O manualmente:

```bash
pkg install git      # Termux
apt install git      # proot-Ubuntu
```

## Uso

```bash
git clone https://github.com/usuario/repo.git
git add .
git commit -m "mensaje"
git push origin main
```

## Notas para Termux

```bash
pkg install git
git --help
```

## Notas para proot-Ubuntu

```bash
apt install git
```

# Node.js

## Descripcion

Entorno de ejecucion de JavaScript del lado del servidor. Incluye
npm (Node Package Manager) para gestion de dependencias.

## Instalacion

```bash
nxai install nodejs
```

O manualmente:

```bash
pkg install nodejs    # Termux
apt install nodejs    # proot-Ubuntu
```

## Uso

```bash
node --version
npm --version
node app.js
```

## Notas para Termux

```bash
pkg install nodejs
```

Node.js funciona perfectamente en Termux. npm tambien esta incluido.

## Notas para proot-Ubuntu

```bash
apt install nodejs npm
```

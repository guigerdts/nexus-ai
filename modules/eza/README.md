# Eza

## Descripcion

Eza es un listador de archivos moderno con soporte de colores, iconos,
arbol de directorios, y metadatos extendidos. Sucesor de exa.

## Instalacion

```bash
nxai install eza
```

O manualmente:

```bash
pkg install eza      # Termux
apt install eza      # proot-Ubuntu
```

## Uso

```bash
eza -la
eza --tree
eza --icons --git
```

# Openclou - CLI de IA para programacion

## Descripcion

Openclou es una CLI de IA para programacion que permite generar,
analizar y refactorizar codigo desde la terminal.

## Instalacion

```bash
nxai install openclou
```

O manualmente:

```bash
# Descarga el binario desde https://openclou.ai
# y hazlo ejecutable:
chmod +x oclou
mv oclou ~/.local/bin/
```

## Uso

```bash
oclou --help
```

## Requisitos

- Linux x86_64 / aarch64
- Conexion a internet

## Notas para Termux

Openclou requiere un binario compatible con ARM64.
Descarga la version adecuada desde https://openclou.ai.
Puede funcionar en proot-Ubuntu si hay compatibilidad.

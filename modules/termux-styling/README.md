# termux-styling — Personalizacion visual de Termux

## Descripcion

Plugin de personalizacion visual para Termux: colores, fuentes y temas.

**URL**: https://github.com/termux/termux-styling

**Instalacion manual — no automatizada**

## Instrucciones

### Instalacion via F-Droid

```bash
# termux-styling se instala via F-Droid (no via apt/pkg)
# 1. Instala F-Droid desde https://f-droid.org
# 2. Busca "Termux:Styling" en F-Droid
# 3. Instala desde la aplicacion
```

### En proot-Ubuntu

No aplica — termux-styling es exclusivo de Termux nativo.

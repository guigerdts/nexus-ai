# Gemini CLI

## Descripcion

CLI oficial de Google Gemini para interactuar con modelos Gemini
directamente desde la terminal.

## Instalacion

```bash
nxai install gemini-cli
```

O manualmente:

```bash
npm install -g @google/gemini-cli
```

## Uso

```bash
gemini --help
```

## Notas para Termux

Requiere Node.js 18+:

```bash
pkg install nodejs
npm install -g @google/gemini-cli
```

## Notas para proot-Ubuntu

```bash
apt install nodejs npm
npm install -g @google/gemini-cli
```

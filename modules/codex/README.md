# Codex - OpenAI Codex CLI (GPT-5.5)

## Descripcion

Codex CLI de OpenAI. Permite generar y ejecutar codigo directamente desde la
terminal usando GPT-5.5.

## Instalacion

```bash
nxai install codex
```

O manualmente:

```bash
npm install -g @openai/codex
```

## Uso

```bash
codex "crea un servidor HTTP en Python"
```

## Requisitos

- Node.js 18+
- npm

## Notas para Termux

Codex funciona en Termux nativo. Instala Node.js primero:

```bash
pkg install nodejs
npm install -g @openai/codex
```

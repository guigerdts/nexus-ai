# Python

## Descripcion

Lenguaje de programacion interpretado, multiparadigma, con una
amplia biblioteca estandar y ecosistema de paquetes via pip.

## Instalacion

```bash
nxai install python
```

O manualmente:

```bash
pkg install python    # Termux
apt install python3  # proot-Ubuntu
```

## Uso

```bash
python3 --version
python3 script.py
pip3 install <paquete>
```

## Notas para Termux

```bash
pkg install python
```

En Termux el paquete `python` incluye pip. Usa `pip3` o `pip`
para instalar paquetes Python.

## Notas para proot-Ubuntu

```bash
apt install python3 python3-pip
python3 --version
```

# Qwen Code - CLI de codigo asistido por Qwen AI

## Descripcion

Qwen Code es un asistido de codigo impulsado por Qwen AI.

## Instalacion

```bash
nxai install qwen-code
```

Instala via npm: `npm install -g @qwen-code/qwen-code`

## Uso

```bash
qwen --help
```

## Requisitos

- Node.js 18+
- npm

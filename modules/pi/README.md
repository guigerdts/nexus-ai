# Pi - Coding Agent CLI

## Descripcion

Pi es un coding agent CLI con herramientas read, bash, edit, write y session management.

## Instalacion

```bash
nxai install pi
```

Instala via npm: `npm install -g --ignore-scripts @earendil-works/pi-coding-agent`

## Uso

```bash
pi --help
```

## Requisitos

- Node.js 18+
- npm

# OpenClaw - Multi-channel AI Gateway

## Descripcion

OpenClaw es un gateway multi-canal de IA con integraciones extensibles para mensajeria.

## Instalacion

```bash
nxai install openclaw
```

Instala via npm: `npm install -g openclaw@latest`

## Uso

```bash
openclaw --help
```

## Requisitos

- Node.js 18+
- npm

# agy

## Descripcion

CLI oficial de Google — asistente de IA desde la terminal.
Reemplazo moderno para gemini-cli.

## Instalacion

```bash
nxai install agy
```

## Uso

```bash
agy --help
```

## Notas

- Instalacion via script oficial de Google: `curl https://antigravity.google/cli/install.sh | bash`
- El binario `agy` queda disponible en el PATH del sistema
- Para verificar: `agy --version`

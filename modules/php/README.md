# PHP — Lenguaje de programacion

## Descripcion

PHP es un lenguaje de programacion ampliamente utilizado para desarrollo web.
Se ejecuta del lado del servidor y esta disenado para crear paginas web
dinamicas.

## Instalacion

```bash
nxai install php
```

O manualmente:

```bash
pkg install php      # Termux
apt install php      # proot-Ubuntu
```

## Uso

```bash
php -v
php script.php
php -S localhost:8000   # Servidor de desarrollo
```

## Notas para Termux

```bash
pkg install php
php --help
```

## Notas para proot-Ubuntu

```bash
apt install php
php --help
```

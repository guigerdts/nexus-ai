# Perl — Lenguaje de programacion

## Descripcion

Perl es un lenguaje de programacion de proposito general conocido por su
potente procesamiento de texto y su amplia coleccion de modulos CPAN.

## Instalacion

```bash
nxai install perl
```

O manualmente:

```bash
pkg install perl      # Termux
apt install perl      # proot-Ubuntu
```

## Uso

```bash
perl -e 'print "Hola, mundo!\n"'
perl script.pl
perl -pe 's/foo/bar/g' archivo.txt
```

## Notas para Termux

```bash
pkg install perl
perl --help
```

## Notas para proot-Ubuntu

```bash
apt install perl
perl --help
```
